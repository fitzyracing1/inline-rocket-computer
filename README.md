# Inline rocket computer

> **Status:** Just an idea. No code or design.

A rocket/spaceship whose computer is fully in line with a single on/off button. You add capability by adding hardware, and gates unlock based on thrust and pressure.

## Where this came from

This idea came up in a chat with one of Joshua Almeida's bots (Lex bot, Oct 26 2026) and was not taken further at the time. This repo records it so it can be picked up later.
